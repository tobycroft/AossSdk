# V3 开放接口（Agnes AI / 邮件 / 文件上传）

V3 是 AOSSTP8 提供的开放接口，当前包含 Agnes AI、邮件（SMTP）与文件上传三类能力。
本模块使用 **V3 凭证信封鉴权**（请求头 `X-Aoss-Ts` / `X-Aoss-Kid` / `X-Aoss-Auth`），
与 V1/V2 的 `?token=` 明文方式完全不同，请勿混用。

## 包导入

```php
use Tobycroft\AossSdk\V3\Ai;
use Tobycroft\AossSdk\V3\AiRet;
use Tobycroft\AossSdk\V3\Mail;
use Tobycroft\AossSdk\V3\MailRet;
use Tobycroft\AossSdk\V3\File;
use Tobycroft\AossSdk\FileRet;
use Tobycroft\AossSdk\FileUrlRet;
use Tobycroft\AossSdk\FileHashRet;
```

> `secret` 由 AOSSTP8 后台「项目管理 v3」页签发（64 位十六进制），请通过配置注入，勿硬编码。

## 构造方法

```php
public function __construct(string $secret, string $baseUrl = '')
```

| 参数 | 类型 | 说明 |
|------|------|------|
| secret | string | 服务端签发的凭证，同时作为信封密钥 |
| baseUrl | string | V3 开放接口域名根，留空则复用 SDK 公用地址 `Aoss::$remote_url` |

```php
$ai = new Ai($secret); // baseUrl 留空则复用 Aoss::$remote_url；也可显式传入
```

所有方法返回 `AiRet`，用法与本 SDK 其它 Ret 一致：

```php
$ret = $ai->chatCompletions($messages);
if ($ret->isSuccess()) {
    $data = $ret->getData(); // 上游原样响应（关联数组）
} else {
    $err = $ret->getError();
}
```

## chatCompletions 对话补全

```php
public function chatCompletions(array $messages, array $options = []): AiRet
```

```php
$ret = $ai->chatCompletions(
    [['role' => 'user', 'content' => '你好']],
    ['model' => 'agnes-3.0-flash', 'max_tokens' => 1024]
);
```

`options` 支持：`model, temperature, max_tokens, top_p, stream, tools, tool_choice, chat_template_kwargs`。

**开启推理（OpenAI 格式）**：

```php
$ret = $ai->chatCompletions($messages, [
    'chat_template_kwargs' => ['enable_thinking' => true],
]);
```

## responses

```php
public function responses(mixed $input, array $options = []): AiRet
```

`$input` 可为字符串或结构化消息；`options` 支持 `model, instructions, temperature,
max_output_tokens, top_p, stream, chat_template_kwargs`（推理开关同上）。

```php
$ret = $ai->responses('总结这个任务并列出需要的工具', ['max_output_tokens' => 1024]);
```

## messages（Anthropic 兼容）

```php
public function messages(array $messages, array $options = []): AiRet
```

`options` 支持：`model, system, temperature, max_tokens, top_p, stream, thinking, chat_template_kwargs`。

**开启推理（Anthropic 格式，注意与 OpenAI 格式不同）**：

$ret = $ai->messages($messages, [

## 邮件（Mail）

```php
$mail = new Mail($secret); // baseUrl 留空则复用 Aoss::$remote_url
$ret = $mail->sendCaptcha('alice@example.com', 'login_code', '882913');
if ($ret->isSuccess()) {
    $data = $ret->getData(); // ['message_id' => '<xxx@host>', 'type' => 'captcha']
} else {
    $err = $ret->getError();
}
```

前置条件：项目已在 AOSSTP8 后台「邮件管理 → 邮件授权」分配至少一台启用中的 SMTP 服务器；
验证码/营销类型还须在「邮件管理 → 邮件模板」配置并启用对应模板。三类内容区别：

| 类型 | 后台维护 | 调用方提供 |
|------|----------|------------|
| 验证码 | 主题、正文模板（含 `{code}`） | `to`、`template`、`code`（≤16 位） |
| 营销 | 主题、正文模板（含 `{变量名}`） | `to`、`template`、`vars` |
| 自定义 | 无 | `to`、`subject`、`body` |

### sendCaptcha 验证码邮件

```php
public function sendCaptcha(string $to, string $template, string $code, array $options = []): MailRet
```

```php
$ret = $mail->sendCaptcha('alice@example.com', 'login_code', '882913', [
    'cc' => 'audit@example.com',
]);
```

`options` 支持：`cc, alt_body, from_addr, from_name, server_id`。

### sendMarketing 营销邮件

```php
public function sendMarketing(string $to, string $template, array $vars, array $options = []): MailRet
```

```php
$ret = $mail->sendMarketing('alice@example.com,bob@example.com', 'promo_spring', [
    'link' => 'https://example.com/promo',
    'name' => '张三',
]);
```

`$vars` 的键对应后台模板里的 `{变量名}`，最多 50 项、单值最长 1000 字符，只接受标量。
有占位符未提供值时会返回失败且不发信。`options` 同 `sendCaptcha`。

### sendCustom 自定义邮件

```php
public function sendCustom(string $to, string $subject, string $body, array $options = []): MailRet
```

```php
$ret = $mail->sendCustom('alice@example.com', '系统通知', '<h3>您好</h3>', [
    'is_html' => 1,
]);
```

`options` 支持：`cc, alt_body, is_html, from_addr, from_name, server_id`。
服务端另保留兼容入口 `/v3/mail/send/index`（等同 `sendCustom`），新代码建议直接使用 `sendCustom`。

## 文件上传（File）

```php
use Tobycroft\AossSdk\V3\File;

$file = new File($secret); // baseUrl 留空则复用 Aoss::$remote_url；也可显式传入
```

**前置条件**：项目已在 AOSSTP8 后台「项目管理 v3」绑定一个启用中的存储项目（`oss_token`）。
未绑定时签发接口返回「项目未绑定存储项目」。存储的大小/后缀/URL 前缀等限制沿用所绑定的
`ao_oss` 存储项目配置。

**上传文件夹（v2.3.0+）**：同一页面的「上传文件夹」字段决定文件落到 `upload/` 下的哪个目录
（如 `product` 或 `site-a/2026`，路径为 `upload/{文件夹}/YYYYMMDD/md5.ext`）。留空则用存储项目名。
local 存本站、OSS 传远程的逻辑不变。该配置由后台维护，SDK 调用方式不受影响；返回 URL 自动带上对应路径。

能力对齐旧版 `File`（`/v2/file/token/*`）：

```php
public function getUploadToken(): FileRet                              // POST /v3/file/token/create
public function getUploadUrl(string $ip = ''): FileUrlRet              // POST /v3/file/token/upload_url
public function getUploadHashUrl(): FileUrlRet                         // POST /v3/file/token/upload_url_hash
public function getUploadedFileUrlByHash(string $hash): FileHashRet    // POST /v3/file/token/hash_query
```

三个 Ret 类（`FileRet` / `FileUrlRet` / `FileHashRet`）与旧版 `doc/file.md` 完全一致，
`isSuccess()` / `getError()` 及属性用法不变，可直接复用原有解析代码。

### 连接与上传流程

1. 后端用 V3 File 换取一次性上传地址（信封鉴权，secret 只在后端）。
2. 把返回的 `$ret->upload_url` 下发给前端；`token` 已含在 URL 的 querystring 中。
3. 前端用 multipart/form-data 直传文件到该地址，字段名固定为 `file`：

```javascript
const formData = new FormData();
formData.append('file', fileInput.files[0]);
const resp = await fetch(uploadUrl, { method: 'POST', body: formData });
const result = await resp.json();
console.log('上传结果:', result.data);
```

4. Hash 模式（`getUploadHashUrl`）上传后仅返回 md5，再用 `getUploadedFileUrlByHash` 查完整信息。

> **为什么直传不带信封头**：浏览器直传无法携带自定义鉴权头，也不能把 secret 交给前端。
> V3 信封鉴权发生在「签发一次性 token」的环节；直传阶段凭一次性 token（`ao_attachment_token`）
> 完成，与 V2 行为一致。一次性 token 有效期 5 分钟、单次使用。

### 完整示例

```php
use Tobycroft\AossSdk\V3\File;

$file = new File($secret);
$urlRet = $file->getUploadUrl();
if (!$urlRet->isSuccess()) {
    // 处理错误（含未绑定存储、项目不可用、限流等）
    echo $urlRet->getError();
}
echo $urlRet->upload_url; // https://.../v3/file/index/upfull?token=xxxx，下发给前端直传

// hash 模式：上传拿到 md5 后查询
$hashRet = $file->getUploadedFileUrlByHash('abc123...');
if ($hashRet->isSuccess()) {
    echo $hashRet->url;
    echo $hashRet->size;
}
```

## 鉴权说明

每次请求都会：取当前秒级时间戳 `ts` → `Envelope::kid(secret)` → `Envelope::seal(secret, ts)`，
并以请求头方式发送，绝不使用 `?token=` 或表单中的明文凭证。
信封实现见 `src/V3/Envelope.php`，已通过 AOSSTP8 服务端参考向量双向验证互通。
